# DML - 등록

## 키워드
- INSERT
## 내용 복습

**INSERT**
- 데이터를 추가할 수 있다.
~~~sql
INSERT INTO table_name (column1, column2, column3, ...)
VALUES (value1, value2, value3, ...);
~~~

- 원하는 특정 열만 추가할 수 있다.
- AUTO_INCREMENT나 DEFAULT 값 설정이 된 열은 명시를 안해도 된다. 


## 요약
- INSERT는 데이터를 추가한다. 
- AUTO_INCREMENT나 DEFAULT처럼 자동으로 값이 등록되는게 있으면 명시를 안해도 된다.
