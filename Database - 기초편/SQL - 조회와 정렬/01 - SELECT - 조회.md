# SELECT - 조회
## 키워드
- SELECT
## 복습 내용
**SELECT**
- 조회가 가능하다.
- SELECT : 무엇을 가져올건가(조회할 열, 컬럼을 지정)
- FROM : 어디에 가져올지( 데이터가 있는 테이블) 

**전체 조회**
~~~sql
SELECT * FROM customers;
~~~
- 모든 열의 테이블을 다 보여준다

**필요한 데이터만 조회하기**
- 전체 조회로 필요한 데이터를 찾을 수는 있지만 민감한 정보나 필요한 정보만 필요할 때가 있다. 
- 만약 테이블에 수백만 데이터가 있다고 할때 `SELECT *` 사용하면 문제가 있다.

1. 성능 저하 : 불필요한 데이터까지 모두 읽어 데이터베이스에 부담을 준다. 조회 속도가 저하된다.
2. 가독성 저하 : 원하는 데이터뿐만 아니라 여러 열이 함께 표시되어 한눈에 파악하기 쉽지 않다.
3. 네트워크 트래픽 낭비 : 데이터베이스 서버에서 클라이언트로 데이터를 전송할때 필요없는 데이터까지 함께 전송되어 네트워크 자원을 낭비하게 된다. 

**특정 열만 선택하기**
~~~sql
SELECT 열이름1, 열이름2, ... FROM 테이블이름;
~~~


**실무에서 사용 별칭 붙이기 : AS**
name이나 email같은 열 이름은 개발자에게 익숙하지만 관련 외에 사람들에게는 직관적이지 않다. 이때 별칭(Alias)을 붙여 조회 결과의 헤더를 바꿀 수 있다.
~~~sql
SELECT 열이름1 AS 별칭1, 열이름2 AS 별칭2, ... FROM 테이블이름;
~~~
별칭을 사용하는 이유
- 보고서 가독성 향상 :  한글로 표시하면 이해하기 쉽다.
- 열 이름 충돌 방지 : 여러 테이블을 조인해서 조회할때 서로 다른 테이블에서 같은 이름의 열이 존재할 수 있다. 이때 별칭을 사용해 각 열을 명확하게 구분한다.
## 요약
- SELECT는 조회를 할 수 있는 명령어이다.
- 전체 조회를 할 수 있으나 필요한 데이터도 조회가 가능하다.
- 조회할때 별칭을 붙이는 습관이 좋다.
