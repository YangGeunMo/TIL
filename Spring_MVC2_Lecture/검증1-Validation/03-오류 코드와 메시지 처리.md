# 오류 코드와 메시지 처리

### 목표
오류 메시지를 체계적으로 다루기 

## FieldError 생성자

FieldError 생성자는 두 가지 생성자를 제공한다. 
~~~java
public FieldError(String objectName, String field, String defaultMessage);

public FieldError(String objectName, String field, @Nullable Object rejectedValue, boolean bindingFailure, @Nullable String[] codes, @Nullable Object[] arguments, @Nullable String defaultMessage)
~~~

FieldError 생성자 파라미터 목록
- `objectName` : 오류가 발생한 객체 이름
- `field` : 오류 필드
- `rejectedValue` : 사용자가 입력한 값(거절된 값)
- `bindingFailure` : 타입 오류 같은 바인딩 실패인지, 검증 실패인지 구분 값
- `codes` : 메시지 코드
- `arguments` : 메시지에서 사용하는 인자
- `defaultMessage` : 기본 오류 메시지

파라미터 목록에서 codes와 arguments 파라미터를 이용해 오류가 발생하면 오류코드로 메시지를 찾을 수 있다.
### V2코드
~~~java
bindingResult.addError(new FieldError("item", "quantity", item.getQuantity(), false, null, null, "수량은 최대 9,999 까지 허용합니다."));
~~~

V2코드에서 코드를 보면 파라미터를 너무 많이 설정해야하고 기본 오류 메시지를 매번 작성해야해서 번거롭다. errors.properties를 추가해 간단하게 만들어보자.

### errors.properties
~~~java
required.item.itemName=상품 이름은 필수입니다.
range.item.price=가격은 {0} ~ {1} 까지 허용합니다.
max.item.quantity=수량은 최대 {0} 까지 허용합니다.
totalPriceMin=가격 * 수량의 합은 {0}원 이상이어야 합니다. 현재 값 = {1}
~~~

### errors.properties를 적용
~~~java
//range.item.price=가격은 {0} ~ {1} 까지 허용합니다.
new FieldError("item", "price", item.getPrice(), false, new String[] {"range.item.price"}, new Object[]{1000, 1000000}
~~~

코드를 보면 
- new String[] {"range.item.price"}이 부분이 codes이고 메시지 코드를 지정한다.
-  new Object[]{1000, 1000000}는 arguments이고 메시지에 사용되는 인자이다. errors.properties에 있는 range.item.price 메시지 내용의 {0} ~ {1}로 치환한다.


## Error 코드를 -> BindingResult의 rejectValue(), reject()로 변경하기
- 코드를 보면 FieldError, ObjectError를 다루기 번거롭고 더 간결하게 하고 싶다.
- rejectValue(), reject()를 사용하면 FieldError, ObjectError를 사용하지 않도 더 간결하게 오류 검증을 다룰 수 있다.

### rejectValue() 알아보기

~~~java
void rejectValue(@Nullable String field, String errorCode,
@Nullable Object[] errorArgs, @Nullable String defaultMessage);
~~~
- `field` : 오류 필드명
- `errorCode` : 오류 코드(이 오류 코드는 메시지에 등록된 코드가 아니다. 뒤에서 설명할 messageResolver를 위한 오류 코드이다.)
- `errorArgs` : 오류 메시지에서 `{0}` 을 치환하기 위한 값
- `defaultMessage` : 오류 메시지를 찾을 수 없을 때 사용하는 기본 메시지

### 사용 예시
~~~java
bindingResult.rejectValue("price", "range", new Object[]{1000, 1000000}, null)
~~~
- 결과 : 가격은 1000 ~ 10000 까지 허용합니다.
- rejectValue()를 사용해 전에 코드보다 더 간결해진걸 알 수 있다.

그런데 전의 코드를 보면 range.item.price 처럼 메시지 코드를 풀 네임으로 작성했는데 rejectValue를 사용하니 메시지 코드를 간결하게 range만 사용해 오류 메시지를 찾아 출력했다. 이유는 MessageCodesResolver를 사용해서 그렇다.
