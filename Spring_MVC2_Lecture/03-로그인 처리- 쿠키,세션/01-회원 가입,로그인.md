## 회원가입  

### Member

~~~java
@Data
public class Member {

    private Long id;

    @NotEmpty
    private String loginId;//로그인 id
    @NotEmpty
    private String name; //사용자 이름
    @NotEmpty
    private String password; // 비밀번호
}
~~~

### MemberRepository
~~~java
/**
 * 동시성 문제가 고려되어 있지 않음, 실무에서는 ConcurrentHashMap, AtomicLong 사용 고려
 */
@Slf4j
@Repository
public class MemberRepository {


    private static Map<Long, Member> store = new HashMap<>();
    private static long sequence = 0L;


    //회원 저장
    public Member save(Member member) {
        member.setId(++sequence);
        log.info("save: member={}", member);
        store.put(member.getId(), member);
        return member;
    }

    //회원 찾기
    public Member findById(Long id) {
        return store.get(id);
    }

    //로그인 아이디로 회원 찾기
    public Optional<Member> findByLoginId(String loginId) {
        return findAll().stream()
                .filter(m -> m.getLoginId().equals(loginId))
                .findFirst();
    }

    //전체 조회
    public List<Member> findAll() {
        return new ArrayList<>(store.values());
    }

    public void clearStore(){
        store.clear();
    }
}
~~~

### MemberController
~~~java
@Controller
@RequiredArgsConstructor
@RequestMapping("/members")
public class MemberController {

    private final MemberRepository memberRepository;


    @GetMapping("/add")
    //타임리프를 오브젝트로 받으므로 객체 모델이 있어야 한다
    public String addForm(@ModelAttribute("member") Member member) {
        return "members/addMemberForm";
    }

    @PostMapping("/add")
    // 요청 파라미터의 값을 Member 객체의 같은 이름 필드에 채운다.
    // @Valid로 Member의 검증 어노테이션을 실행하고, 실패하면 오류를 bindingResult에 담는다.
    // BindingResult는 검증 대상 객체 바로 뒤에 와야 한다.
    public String save(@Valid @ModelAttribute Member member, BindingResult bindingResult) {
        if (bindingResult.hasErrors()) {
            return "members/addMemberForm";
        }

        memberRepository.save(member);
        return "redirect:/";
    }
}
~~~
회원가입을 하면 메모리에 등록된다. 
~~~
Member(id=2, loginId=test, name=123, password=123)
~~~

## 로그인 기능

회원가입한 아이디로 로그인이 가능하게 개발해보자.

## LoginService
~~~java
@Service
@RequiredArgsConstructor
//로그인 기능
public class LoginService {

    private final MemberRepository memberRepository;
    /**
        * @return null이면 로그인 실패
    */
    // 로그인 아이디와 비밀번호 파라미터를 받는다.
    // 아이디가 없거나 비밀번호가 틀리면 null을 반환
    public Member login(String loginId, String password) {
        return memberRepository.findByLoginId(loginId)
                .filter(m -> m.getPassword().equals(password))
                .orElse(null);
    }
}
~~~
- 회원을 아이디와 비밀번호 파라미터가 들어오면 아이디를 조회한 후 비밀번호가 같으면 회훤을 반환한다. 비밀번호가 다를 경우 null을 반환한다.
### LoginForm

~~~java
@Data
public class LoginForm {

    @NotEmpty
    private String loginId;

    @NotEmpty
    private String password;
}
~~~
- 로그인은 아이디와 비밀번호만 필요하므로, 회원 전체 정보를 담는 Member 대신 로그인 입력만 담는 LoginForm을 만든다. 화면 입력과 검증 조건을 로그인 목적에 맞게 따로 관리하기 위해서다. 

### LoginController
~~~java
    @PostMapping("/login")
    //요청 파라미터를 LoginForm 객체에 담는다.
    //@Valid로 LoginForm에 있는 검증 어노테이션을 실행하고 검증 오류를 bindingResult에 담는다.
    public String loginV1(@Valid @ModelAttribute LoginForm form, BindingResult bindingResult) {
        if (bindingResult.hasErrors()) {
            return "login/loginForm";
        }
        // 로그인 성공하면 일치하는 회원을 반환
        Member loginMember = loginService.login(form.getLoginId(), form.getPassword());

        if (loginMember == null) {
            bindingResult.reject("loginFail", "아이디 또는 비밀번호가 맞지 않습니다.");
            return "login/loginForm";
        }

        //로그인 성공 처리


        return "redirect:/";
    }
~~~

로그인이 성공하면 홈화면으로 이동하고 실패하면 글로벌 오류(ObjectError)를 생성하고 정보를 다시 입력하도록 로그인 폼으로 이동한다.
