# 로그인 처리하기 - 쿠키 사용 

쿠키를 사용해 로그인, 로그아웃 기능을 구현하기

## 로그인 상태 유지
로그인 상태를 유지하려면 쿼리 파라미터를 계속 서버에 보내야 하는데 매우 번거로운 작업이다. 쿠키를 사용하면 해결할 수 있다.

## 쿠키

서버에서 로그인을 성공하면 HTTP 응답에 쿠키를 담아서 브라우저에게 전달한다. 그러면 브라우저는 앞으로 모든 요청에 쿠키 정보를 자동으로 포함해서 전달한다.

### 쿠키는 영속 쿠키와 세션 쿠키가 있다.
- 영속 쿠키 : 만료 날짜를 입력하면 해당 날짜까지 유지
- 세션 쿠키 : 만료 날짜를 생략하면 브라우저를 종료할때까지 유지

## 쿠키 생성 

~~~java
Cookie idCookie = new Cookie("memberId", String.valueOf(loginMember.getId()));
response.addCookie(idCookie);
~~~

로그인에 성공하면 쿠키를 생성하고 response에 담아 브라우저에 전달한다. 웹 브라우저는 종료 전까지 계속 쿠키를 서버에 자동 전송한다.  

### LoginController에 쿠키 추가

~~~java
 //@PostMapping("/login")
    //요청 파라미터를 LoginForm 객체에 담는다.
    //@Valid로 LoginForm에 있는 검증 어노테이션을 실행하고 검증 오류를 bindingResult에 담는다.
    public String loginV1(@Valid @ModelAttribute LoginForm form, BindingResult bindingResult, HttpServletResponse response) {
        if (bindingResult.hasErrors()) {
            return "login/loginForm";
        }
        // 로그인 성공하면 일치하는 회원을 반환
        Member loginMember = loginService.login(form.getLoginId(), form.getPassword());

        if (loginMember == null) {
            bindingResult.reject("loginFail", "아이디 또는 비밀번호가 맞지 않습니다.");
            return "login/loginForm";
        }


        //로그인 성공 처리


        // 만료 시간을 지정하지 않으면 세션 쿠키가 되어 브라우저를 종료하면 삭제된다.
        // 쿠키 이름은 memberId, 값은 로그인한 회원의 id로 만든다.
        Cookie idCookie = new Cookie("memberId", String.valueOf(loginMember.getId()));
        //만든 쿠키를 응답 헤더에 Set-Cookie를 추가
        response.addCookie(idCookie);
        return "redirect:/";
    }
~~~

### 로그인 처리 - 화면에 로그인한 유저 정보 출력
~~~java
    @GetMapping("/")
    // 쿠키 이름이 memberId인 값을 찾아서 Long으로 변환해 memberId에 담는다.
    //(@CookieValue로 쿠키를 조회한다. 쿠키가 없으면 null이 들어온다.(required = false : 쿠키가 없으면 null)
    public String homeLoginV1(@CookieValue(name = "memberId", required = false) Long memberId, Model model) {
        //쿠키가 없으면 로그인을 하지 않은 상태이므로 비로그인 홈 화면으로 이동한다.
        if (memberId == null) {
            return "home";
        }

        //쿠키의 회원 id로 회원을 조회한다.
        Member loginMember = memberRepository.findById(memberId);
        if (loginMember == null) {
            return "home";
        }
        // 찾은 회원 정보를 모델에 담아 로그인 홈 화면에 표시한다.
        model.addAttribute("member", loginMember);
        return "loginHome";
    }
~~~

- @CookieValue로 쿠키를 조회하고 쿠키 이름이 memberId를 찾ㅈ아 memberId변수에 담는다.
- 쿠키에 등록된 회원 id를 조회하고 찾은 회원 정보를 모델에 담아 화면에 표시한다.

## 로그아웃 

로그아웃 방법

- 세션 쿠키이므로 웹 브라우저 종료
- 서버에서 해당 쿠키의 종료 날짜를 0으로 지정

~~~java
    @PostMapping("/logout")
    // 응답에 쿠키 삭제를 실어 보내기 위해 HttpServletResponse를 받는다.
    public String logoutV1(HttpServletResponse response) {
        expireCookie(response,"memberId");
        return "redirect:/";
    }

    private void expireCookie(HttpServletResponse response,String cookieName) {
        //이름을 "memberId"로 하고 값이 null인 쿠키를 만든다.
        Cookie cookie = new Cookie(cookieName, null);
        // 쿠키 시간을 0으로 즉시 만료
        cookie.setMaxAge(0);
        // 응답 헤더에 Set-Cookie로 추가해 브라우저가 기존 쿠키를 삭제하게 한다.
        response.addCookie(cookie);
    }
~~~
- 쿠키를 서버에서 응답으로 웹브라우저에게 보낼때 쿠키 시간이 0이므로 받는 웹브라우저는 해당 쿠키가 즉시 종료된다.
