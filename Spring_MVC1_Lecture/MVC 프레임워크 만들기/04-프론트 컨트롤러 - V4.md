# 프론트 컨트롤러 - V4

## 단순하고 실용적인 컨트롤러

* v3에서 컨트롤러는 종속성을 제거하고 뷰 경로의 중복을 제거 했다.
* 그런데 컨트롤러 인터페이스를 구현하는 개발자 입장에서는 항상 ModelView 객체를 생성하고 반환해야하므로 번거롭다. 
* 좋은 프레임워크는 아키텍처도 중요하나 개발자가 단순하고 편리하게 사용할 수 있어야 한다. 
* V4에서는 개발자가 편리하게 개발할 수 있게 변형한다. 

#### V4 구조

* V3와 같은 구조인데 컨트롤러가 ModelView가 아닌 ViewName만 반환한다. 
```java
public interface ControllerV4 {

    /**
     *
     * @param paramMap
     * @param model
     * @return viewName
     */
    String process(Map<String, String> paramMap, Map<String, Object> model);
}

```
* V4인터페이스는 결과로 뷰 이름만 반환해준다. 

#### 회원 등록 컨트롤러 - V4
```java
public class MemberFormControllerV4 implements ControllerV4 {

    @Override
    public String process(Map<String, String> paramMap, Map<String, Object> model) {
        return "new-form";
    }
}

```

* new-form이라는 뷰 논리 이름만 반환한다. 

#### 회원 저장 컨트롤러 - V4
```java
public class MemberSaveControllerV4 implements ControllerV4 {

    private MemberRepository memberRepository = MemberRepository.getInstance();

    @Override
    public String process(Map<String, String> paramMap, Map<String, Object> model) {

        //요청 파라미터를 Map에서 가져온다
        String username = paramMap.get("username");
        int age = Integer.parseInt(paramMap.get("age"));

        //Member 객체 생성 및 저장소에 저장
        Member member = new Member(username, age);
        memberRepository.save(member);

        //생성한 Member 객체를 model에 저장한다. 
        model.put("member", member);
        return "save-result";
    }
}
```

#### 회원 목록 컨트롤러 - V4
```java
public class MemberListControllerV4 implements ControllerV4 {

    private MemberRepository memberRepository = MemberRepository.getInstance();

    @Override
    public String process(Map<String, String> paramMap, Map<String, Object> model) {
        // 저장소에서 모든 회원 조회
        List<Member> members = memberRepository.findAll();

        //조회한 회원을 model에 저장 
        model.put("members", members);
        
        //뷰 논리 반환 
        return "members";
    }
}
```

#### 프론트 컨트롤러 - V4
```java
@WebServlet(name = "fronControllerServletV4",urlPatterns = "/front-controller/v4/*")
public class FronControllerServletV4 extends HttpServlet {
    //key,value로 받는 자료구조 정의
    private Map<String, ControllerV4> controllerMap = new HashMap<>();
    // WAS가 시작되면서 Servlet이 초기화될 때 기본 생성자 실행되고 Map에 key, value로 저장된다.
    public FronControllerServletV4() {
        controllerMap.put("/front-controller/v4/members/new-form", new MemberFormControllerV4());
        controllerMap.put("/front-controller/v4/members/save", new MemberSaveControllerV4());
        controllerMap.put("/front-controller/v4/members", new MemberListControllerV4());
    }

    @Override
    protected void service(HttpServletRequest request, HttpServletResponse response) throws ServletException, IOException {

        // 요청한 URL을 가져온다
        String requestURI = request.getRequestURI();

        // 요청 URL에 맞는 Controller를 찾는다
        ControllerV4 controller = controllerMap.get(requestURI);
        if (controller == null) {
            response.setStatus(HttpServletResponse.SC_NOT_FOUND);
            return;
        }

        // 요청받은 파라미터를 Map으로 변환한다
        Map<String, String> paramMap = createParamMap(request);

        // V4의 개선점: FrontController에서 model을 미리 생성한다
        // (V3과 달리 Controller에서 ModelView를 생성할 필요 없음)
        Map<String, Object> model = new HashMap<>();

        // Controller를 호출하고 뷰 이름(String)을 반환받는다
        String viewName = controller.process(paramMap, model);

        // 논리 뷰 이름을 물리 뷰 경로로 변환한다
        MyView view = viewResolver(viewName);

        // MyView의 render()를 호출해서 JSP로 forward한다
        view.render(model, request, response);
    }

    // 논리 뷰 이름을 물리 뷰 경로로 변환한다
    // 예: "save-result" → "/WEB-INF/views/save-result.jsp"
    private static MyView viewResolver(String viewName) {
        return new MyView("/WEB-INF/views/" + viewName + ".jsp");
    }

    // 요청받은 파라미터를 Map에 저장한다
    private static Map<String, String> createParamMap(HttpServletRequest request) {
        Map<String, String> paramMap = new HashMap<>();

        // 요청의 모든 파라미터 이름을 가져와서
        // 각 파라미터의 이름과 값을 Map에 저장한다
        request.getParameterNames().asIterator()
                .forEachRemaining(paramName -> paramMap.put(paramName, request.getParameter(paramName)));

        return paramMap;
    }
}

```

#### 모델 객체 전달
`Map<String, Object> model = new HashMap<>(); //추가`
* 모델 객체를 프론트 컨트롤러에서 생성해서 컨트롤러에게 넘겨준다. 모델 객체에 값을 담으면 여기에 담긴다.
