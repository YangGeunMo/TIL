# 프론트 컨트롤러 - V3

## Model 추가 

#### 서블릿 종속성 제거
* 컨트롤러 입장에서 request, response가 필요한지 의문이다.
* 요청 파라미터 정보를 자바 Map으로 대신 넘기면 컨트롤러가 서블릿 기술을 몰라도 동작하게 할 수 있다. 
* 이러면 request 객체를 Model로 사용하는 대신 별도의 Model 객체를 만들어 반환하면 된다. 
* 서블릿 기술을 사용하지 않고 변경할 경우 코드가 단순해지고 테스트 코드 작성이 쉽다. 

#### 뷰 이름 중복 제거
- V2에서 컨트롤에서 지정하는 뷰 이름에 중복이 있다.
- 컨트롤러는 논리 이름만 반환하고 실제 물리 위치는 프론트 컨트롤러에서 처리하도록  한다. 
- 이렇게 하면 나중에 뷰의 폴더 위치가 변경되어도 프론트 컨트롤러만 고치면 된다. 
- `/WEB-INF/views/new-form.jsp` **new-form**
- `/WEB-INF/views/save-result.jsp` **save-result**
- `/WEB-INF/views/members.jsp` **members**

## ModelView 클래스

```java
/**
 * V3에서 Controller가 반환하는 객체
 * View 정보와 Model 데이터를 함께 담는다
 */
public class ModelView {

    // 뷰 이름 예: new-form
    // 경로가 아님! FrontController에서 경로로 변환
    private String viewName;
    
    // Model 데이터 저장소 (데이터를 저장해서 View로 전달)
    private Map<String, Object> model = new HashMap<>();

    public ModelView(String viewName) {
        this.viewName = viewName;
    }

    public String getViewName() {
        return viewName;
    }

    public void setViewName(String viewName) {
        this.viewName = viewName;
    }

    // Model 데이터를 조회한다
    public Map<String, Object> getModel() {
        return model;
    }

    public void setModel(Map<String, Object> model) {
        this.model = model;
    }
}
```

#### ControllerV3

```java
public interface ControllerV3 {
    // HTTP 요청을 저장하는 Map
    ModelView process(Map<String, String> paramMap);
}

```
* 서블릿을 사용하지 않기에 구현이 단순하고 테스트 코드 작성시 테스트 하기 쉽다.
* HttpServletRequest가 제공하는 파라미터를 프론트 컨트롤러에서 paramMap에 담아 호출해주면 된다. 
* 응답 결과는 View이름, Model 데이터를 포함한 ModelView 객체를 반환하면 된다.

#### 회원 등록 컨트롤러 - V3

```java
public class MemberFormControllerV3 implements ControllerV3 {
    @Override
    public ModelView process(Map<String, String> paramMap) {
        return new ModelView("new-form");

}
```

#### 회원 저장 컨트롤러 - V3
```java

public class MemberSaveControllerV3 implements ControllerV3 {

    private MemberRepository memberRepository = MemberRepository.getInstance();

    @Override
    public ModelView process(Map<String, String> paramMap) {
        //요청 파라미터를 Map에서 가져온다.
        String username = paramMap.get("username");
        int age = Integer.parseInt(paramMap.get("age"));
        //Member 객체에 생성하고 저장한다.
        Member member = new Member(username, age);
        memberRepository.save(member);

        //ModelView 객체를 생성하고 뷰 이름만 저장
        ModelView mv = new ModelView("save-result");

        //Model(데이터 저장소)을 가져와서 데이터를 추가한다
        //getModel()로 Map을 꺼낸 후 put으로 데이터 추가
        mv.getModel().put("member", member);
        return mv;
    }
}

```

#### 회원 목록 컨트롤러 - V3 

```java
//회원 목록 조회 컨트롤러 V3
public class MemberListControllerV3 implements ControllerV3 {

    private MemberRepository memberRepository = MemberRepository.getInstance();

    @Override
    public ModelView process(Map<String, String> paramMap) {
        
        // 저장소에서 모든 회원을 조회한다
        List<Member> members = memberRepository.findAll();

        // ModelView 객체 생성하고 뷰 이름을 저장한다
        ModelView mv = new ModelView("members");
        
        // Model(데이터 저장소)에 조회한 회원 목록을 저장한다
        mv.getModel().put("members", members);
        
        return mv;
    }
}
```

#### 프론트 컨트롤러 - V3

```java
@Override
protected void service(HttpServletRequest request, HttpServletResponse response) throws ServletException, IOException {

    // 요청한 URL을 가져온다
    String requestURI = request.getRequestURI();
    
    // 요청 URL에 맞는 Controller를 찾는다
    ControllerV3 controller = controllerMap.get(requestURI);
    if (controller == null) {
        response.setStatus(HttpServletResponse.SC_NOT_FOUND);
        return;
    }

    // 요청받은 파라미터를 Map으로 변환해서 저장한다
    Map<String, String> paramMap = createParamMap(request);

    // paramMap으로 Controller를 호출하고 ModelView를 반환받는다
    ModelView mv = controller.process(paramMap);
    
    // ModelView에서 뷰 이름(논리명)을 가져온다
    String viewName = mv.getViewName();  // 예: "save-result"

    // 논리 이름을 물리 뷰 경로로 변환하고 MyView 객체를 반환한다
    MyView view = viewResolver(viewName);

    // MyView의 render()를 호출해서 JSP로 forward한다
    // Model 데이터를 JSP에 전달한다
    view.render(mv.getModel(), request, response);
}

// 논리 뷰 이름을 물리 뷰 경로로 변환한다
// 예: "save-result" → "/WEB-INF/views/save-result.jsp"
private static MyView viewResolver(String viewName) {
    return new MyView("/WEB-INF/views/" + viewName + ".jsp");
}

// 요청받은 파라미터를 Map에 저장한다
private static Map<String, String> createParamMap(HttpServletRequest request) {
    Map<String, String> paramMap = new HashMap<>();

    // 요청의 모든 파라미터 이름을 가져와서
    // 각 파라미터의 이름과 값을 Map에 저장한다
    request.getParameterNames().asIterator()
            .forEachRemaining(paramName -> paramMap.put(paramName, request.getParameter(paramName)));

    return paramMap;
}
```

* createParamMap() 메서드 
  * HttpServletRequest에서 파라미터 정보를 꺼내 Map으로 변환한다.

#### 뷰 리졸버
* 컨트롤러가 반환한 논리 뷰를 실제 물리 뷰로 변경하고 물리 경로가 있는 MyView 객체를 반환한다. 


view.render(mv.getModel(), request, response)
* 뷰 객체를 통해 HTML화면을 렌더링 한다. 
* 모델 정보도 같이 받는다. 
* JSP는 request.getAttribute()로 데이터를 조회하기 때문에 모델의 데이터를 꺼내서 request.setAttribute()로 담아둔다. 
* JSP로 포워드 해서 JSP를 렌더링을 한다.

```java
public void render(Map<String, Object> model, HttpServletRequest request, HttpServletResponse response) throws ServletException, IOException {
    // Model 데이터를 request 속성으로 변환한다
    // (JSP에서 getAttribute()로 꺼낼 수 있게 하기 위함)
    modelToRequestAttribute(model, request);

    // viewPath에 해당하는 JSP로 forward한다
    RequestDispatcher dispatcher = request.getRequestDispatcher(viewPath);
    dispatcher.forward(request, response);
}

// Model(Map)의 데이터를 request 속성으로 변환한다
private static void modelToRequestAttribute(Map<String, Object> model, HttpServletRequest request) {
    // Model의 모든 데이터를 순회하면서
    // 각 key, value를 request에 setAttribute()로 저장한다
    model.forEach((key, value) -> request.setAttribute(key, value));
}
```

#### 동작흐름 

```
클라이언트 요청
/front-controller/v3/members/save

URL확인 후 변수 저장
String requestURI = request.getRequestURI();

URL에 맞는 Controller를 찾고 변수 저장
ControllerV3 controller = controllerMap.get(requestURI);

요청 파라미터를 Map으로 변환

변환한 paramMap으로 컨트롤러를 호출하고 ModelView 를 반환
ModelView mv = controller.process(paramMap);

반환한 ModelView 객체에서 논리 뷰 이름을 ViewResolver 함수를 통해 물리 뷰로 변경하고 물리 뷰 경로가 저장되 있는 MyView 객체를 반환한다.
MyView view = viewResolver(viewName); 

MyView의 render메서드를 호출해서 Model 데이터, 요청,응답 받아 처리 후 forward를 해서 JSP를 렌더링 한다. 
```

* V2에서 V3로 변경하며서 서블릿을 사용안하고 자바 코드로만 작성해서 컨트롤러 등 구현 코드가 단순해 졌다. 
* 뷰 경로도 폴더 위치가 바뀌면 프론트 컨트롤러만 변경하면 된다.
