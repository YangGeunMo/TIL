문제점
* 각 클라이언트가 어떤 클라이언트를 호출해야 하는지 알아야 한다. 
* 코드의 중복
```
ControllerA에서:
String viewPath = "/WEB-INF/views/new-form.jsp";
RequestDispatcher dispatcher = request.getRequestDispatcher(viewPath);
dispatcher.forward(request, response);

ControllerB에서:
String viewPath = "/WEB-INF/views/save-result.jsp";
RequestDispatcher dispatcher = request.getRequestDispatcher(viewPath);
dispatcher.forward(request, response);

→ forward 코드가 매 컨트롤러마다 중복
```
* 공통처리가 어렵다.

### 프론트 컨트롤러 도입 후 
<img width="772" height="391" alt="image" src="https://github.com/user-attachments/assets/89a90735-50ae-44e6-b945-e6b5129712fc" />

* 프론트 컨트롤러 서블릿 하나로 모든 클라이언트의 요청을 받는다.
* 프론트 컨트롤러가 요청에 맞는 컨트롤러를 찾아 호출해준다. 
* 공통처리가 가능하다. 
* 프론트 컨트롤러를 제외한 나머지 컨트롤러는 서블릿을 사용하지 않아도 된다.

**프론트 컨트롤러 도입을 v1부터v5까지 단계적으로 도입**

* 기존 코드는 최대한 유지하면서 프론트 컨트롤러 도입하기 
* 구조를 맞추고 점진적으로 리펙토링하기

# 프론트 컨트롤러 도입 - V1

## V1구조 
<img width="778" height="429" alt="스크린샷 2026-10-03 오후 3 03 18" src="https://github.com/user-attachments/assets/02afd62d-3be1-43b8-b1fb-4e26157e7322" />

```
//모든 컨트롤러가 구현해야할 인터페이스
public interface ControllerV1 {
    void process(HttpServletRequest request, HttpServletResponse response) throws ServletException, IOException;
}

```

* 서블릿과 비슷한 모양의 컨트롤러 인터페이스를 도입. 각 클랙스는 이 인터페이스를 구현한다. 
* 프론트 컨트롤러는 이 인터페이스를 호출해서 구현과 관계 없이 로직의 일관성을 가져올 수 있다. 
* 프론트 컨트롤러에서 ControllerV1 타입으로 통일 가능하다( 다형성)

#### 회원 등록 컨트롤러
```
//회원 등록 폼 컨트롤러
public class MemberFormControllerV1 implements ControllerV1 {
    @Override
    public void process(HttpServletRequest request, HttpServletResponse response) throws ServletException, IOException {
        String viewPath = "/WEB-INF/views/new-form.jsp";
        
        // JSP의 경로를 지정한다
        RequestDispatcher dispatcher = request.getRequestDispatcher(viewPath);
        
        // JSP로 forward한다
        // request: 클라이언트 요청 정보를 담고 있음 (JSP에서 getParameter 가능)
        // response: 비어있음 (JSP에서 HTML을 작성해서 담음)
        dispatcher.forward(request, response);
    }
}
```

#### 회원 저장 컨트롤러 
```
//회원 저장 컨트롤러
public class MemberSaveControllerV1 implements ControllerV1 {

    private MemberRepository memberRepository = MemberRepository.getInstance();

    @Override
    public void process(HttpServletRequest request, HttpServletResponse response) throws ServletException, IOException {
        // 요청 파라미터에서 username과 age를 가져와 변수에 저장
        String username = request.getParameter("username");
        int age = Integer.parseInt(request.getParameter("age"));

        // 비즈니스 로직: Member 객체 생성 및 저장
        Member member = new Member(username, age);
        memberRepository.save(member);

        // Model에 데이터를 보관한다
        // request.setAttribute로 저장된 데이터를 JSP에서 getAttribute로 꺼낼 수 있다
        request.setAttribute("member", member);

        // JSP의 경로를 지정한다
        String viewPath = "/WEB-INF/views/save-result.jsp";
        RequestDispatcher dispatcher = request.getRequestDispatcher(viewPath);
        
        // JSP로 forward한다
        // request: 클라이언트 요청 정보 + setAttribute로 저장한 member 데이터 담겨있음
        // response: 비어있음 (JSP에서 HTML을 작성해서 담음)
        dispatcher.forward(request, response);
    }
}
```
#### 회원 목록 컨트롤러
```
//회원 목록 조회 컨트롤러
public class MemberListControllerV1 implements ControllerV1 {

    private MemberRepository memberRepository = MemberRepository.getInstance();

    @Override
    public void process(HttpServletRequest request, HttpServletResponse response) throws ServletException, IOException {

        // 저장소에서 모든 회원을 조회한다
        List<Member> members = memberRepository.findAll();

        // Model에 데이터를 보관한다
        // request.setAttribute로 저장된 데이터를 JSP에서 getAttribute로 꺼낼 수 있다
        request.setAttribute("members", members);
        
        // JSP의 경로를 지정한다
        String viewPath = "/WEB-INF/views/members.jsp";
        RequestDispatcher dispatcher = request.getRequestDispatcher(viewPath);
        
        // JSP로 forward한다
        // request: 클라이언트 요청 정보 + setAttribute로 저장한 members 데이터 담겨있음
        // response: 비어있음 (JSP에서 HTML을 작성해서 담음)
        dispatcher.forward(request, response);

    }
}
```

#### 프론트 컨트롤러
```
// /front-controller/v1/* 하위의 모든 요청을 처리한다
@WebServlet(name = "fronControllerServletV1", urlPatterns = "/front-controller/v1/*")
public class FronControllerServletV1 extends HttpServlet {
    
    // URL과 Controller를 매핑해서 저장하는 자료구조
    private Map<String, ControllerV1> controllerMap = new HashMap<>();
    
    // WAS가 시작되면서 Servlet이 초기화될 때 기본 생성자 실행되고 
    // controllerMap에 URL과 Controller를 매핑해서 저장한다
    public FronControllerServletV1() {
        controllerMap.put("/front-controller/v1/members/new-form", new MemberFormControllerV1());
        controllerMap.put("/front-controller/v1/members/save", new MemberSaveControllerV1());
        controllerMap.put("/front-controller/v1/members", new MemberListControllerV1());
    }

    @Override
    protected void service(HttpServletRequest request, HttpServletResponse response) throws ServletException, IOException {

        // 클라이언트가 요청한 URL을 가져온다
        String requestURI = request.getRequestURI();
        
        // 요청 URL에 맞는 Controller를 찾는다 (다형성의 핵심)
        // ControllerV1 인터페이스로 통일하면 모든 구현체를 같은 타입으로 처리 가능
        // 만약 인터페이스가 없었다면 각 컨트롤러마다 다르게 호출해야 함
        ControllerV1 controller = controllerMap.get(requestURI);
        
        // 해당하는 Controller가 없으면 404 에러
        if (controller == null) {
            response.setStatus(HttpServletResponse.SC_NOT_FOUND);
            return;
        }

        // 찾은 Controller를 호출한다
        // request: 클라이언트 요청 정보 담겨 있음
        // response: 비어있음 (Controller에서 JSP로 forward할 때 사용)
        controller.process(request, response);
    }
}
```


#### 동작 흐름 

```
1. 클라이언트 요청
   /front-controller/v1/members/save

2. FrontController가 요청 받음
   String requestURI = request.getRequestURI();
   → "/front-controller/v1/members/save" 가져옴

3. URL 매핑 정보 확인
   ControllerV1 controller = controllerMap.get(requestURI);
   → MemberSaveControllerV1 참조값 획득

4. Controller 호출
   controller.process(request, response);
   → MemberSaveControllerV1의 process() 실행
   
   Controller 내부:
   - 요청 파라미터 가져오기 (request.getParameter)
   - 비즈니스 로직 처리 (Member 저장)
   - 결과 데이터를 request에 저장 (request.setAttribute)
   - JSP로 forward (dispatcher.forward)

5. JSP에서 처리
   - request에서 데이터 꺼냄 (request.getAttribute)
   - HTML 생성

6. 클라이언트에게 HTML 응답
   response에 담긴 HTML 전송
   → 브라우저에 표시
```
