## ArgumentResolver 

- 어노테이션 기반의 컨트롤러는 다양한 파라미터를 사용할 수 있었는데(`HttpServletRequest` , `Model`, `RequestParam` , `@ModelAttribute` 등) 이렇게 사용할 수 있는 이유가 ArgumentResolver 때문이다.

- 어노테이션 기반 컨트롤러를 처리하는 RequestMappingHandlerAdapter는 ArgumentResolver호출해서 다양한 파라미터를 만들고 값까지 다 채우고 핸들러 어댑터는 컨트롤러를 호출해서 값들을 파라미터로 넘겨 컨트롤러를 호출한다.

- 정확히는 HandlerMethodArgumentResolver 인데 줄여서 ArgumentResolver 라고 부른다.



### HandlerMethodArgumentResolver 내부

~~~java
public interface HandlerMethodArgumentResolver {

	boolean supportsParameter(MethodParameter parameter);

	@Nullable Object resolveArgument(MethodParameter parameter, @Nullable ModelAndViewContainer mavContainer,
			NativeWebRequest webRequest, @Nullable WebDataBinderFactory binderFactory) throws Exception;
}
~~~

### 동작방식

- ArgumentResolver의 supportsParameter()를 호출해 해당 파라미터를 지원하는지 체크한다. 지원하면 resolveArgument()를 호출하고 객체를 생성한다.그리고 이 객체가 컨트롤러 호출시 넘어간다.
- 그리고 원하는 기능이 있다면 이 인터페이스를 확장해서 원하는 `ArgumentResolver` 를 만들 수도 있다. (실제 확장은 로그인 처리에서 해본다)


## ReturnValueHandler
- HandlerMethodReturnValueHandler 를 줄여서 ReturnValueHandler라 부른다.
- ReturnValueHandler는 응답 값을 변환하고 처리한다.
- 컨트롤러에서 String으로 뷰 이름을 반환해도, 동작하는 이유가 바로 ReturnValueHandler 때문이다.


## HTTP 메시지 컨버터

HTTP 메시지 컨버터 위치

<img width="781" height="406" alt="스크린샷 2026-10-08 오전 2 58 50" src="https://github.com/user-attachments/assets/d6210635-2e61-46d7-ba6f-38bfad0f4097" />

- HTTP 메시지 컨버터를 사용하는 @RequestBody 컨트롤러가 필요하는 파라미터 값에 사용된다.
- @ResponseBody도 컨트롤러 반환값에 사용된다.

요청의 경우
- @RequestBody 를 처리하는 ArgumentResolver, HttpEntity 를 처리하는 ArgumentResolver가 있는데 이 ArgumentResolver들이 HTTP 메시지 컨버터를 사용해서 필요한 객체를 생성한다.

응답의 경우
- @ResponseBody 와 HttpEntity 를 처리하는 ReturnValueHandler 가 있고 HTTP 메시지 컨버터를 호출해서 응답 결과를 만든다. 


## 정리
### ArgumentResolver와 HTTP 메시지 컨버터의 관계

- 핸들러 어댑터가 요청을 받으면, ArgumentResolver는 컨트롤러의 각 파라미터가 어떤 타입인지 확인한다.(@RequestBody, @RequestParam, HttpServletRequest, Model 등)

- 그 과정에서 각 ArgumentResolver는 파라미터에 맞게 필요한 작업을 수행한다. 특히 @RequestBody 같이 HTTP 메시지 본문을 처리해야 하는 파라미터의 경우, ArgumentResolver가 HTTP 메시지 컨버터를 호출해서 JSON 형식의 데이터를 객체로 변환한다.

- 변환된 객체는 자동으로 필드명을 매칭해서 JSON의 값들을 객체의 프로퍼티에 넣는다.

- 응답할 때도 마찬가지로, ReturnValueHandler가 처리할 때 HTTP 메시지 컨버터를 사용해서 객체를 JSON 형식으로 자동 변환한 후 클라이언트에게 전송한다.
